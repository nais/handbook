# Properties of Nais

These are the core properties we strive to uphold and improve in every part of Nais. They are the
properties we prioritize by when deciding what to build and how — not a pitch for what a team
using Nais gets (that's [nais.io](https://nais.io)), but the criteria we weigh against when we
decide where to spend our effort.

## Automation over manual toil

We automate rather than adding manual steps or process. If something needs to be done more than
once, it should be a feature of the platform, not a runbook.

## Secure by Design

Security is not an afterthought. We build resilient solutions and empower teams to protect
themselves effectively.

## Accountable

We build so that we can always answer who did what, and when. Traceability is part of the design,
not something bolted on when an incident forces the question.

## Cost-Conscious

Being stewards of taxpayer money, we are always looking for ways to optimize costs and reduce
waste. We do this on the platform itself, and by providing the teams with cost and utilization
insights.

## Sustainable pace

We build with care, reducing technical debt as we go, while staying up-to-date on what's happening
in the industry. This keeps development fast and frictionless — not just today, but over time.

## Sovereign & Autonomous

We build on industry standards rather than proprietary lock-in — both in the platform itself and in
how workloads integrate with it. This keeps two things possible: the code teams run on Nais can run
elsewhere, and we can move the platform itself if the world changes.
